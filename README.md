# SuperChoice AI

A community academy for people learning to work with coding agents: a journal, a free **pstack Fundamentals** course, a timed exam, and a community certificate.

This site was generated by [Lovable](https://lovable.dev) and stays on that stack: Vite, React, TypeScript, Tailwind, TanStack Start, and TanStack Router file routes in `src/routes`. The package manager is Bun (`bun.lock`, `bunfig.toml`).

Certificates are community credentials issued by SuperChoice AI. They are not affiliated with or endorsed by Cursor, xAI, or Lauren Tan.

## Run

```sh
bun install
bun run dev
```

Other checks:

```sh
bun run build
bun run lint
bun run test
```

The dev server prints a local URL. Production output is the TanStack Start / Nitro build in `.output`.

## Add a post

Create a folder and one Markdown file per language:

```text
src/content/posts/<slug>/en.md
src/content/posts/<slug>/th.md
```

Frontmatter:

```yaml
title: "Post title"
date: 2026-11-08
summary: "One or two sentences."
tags: engineering, pstack
author: SuperChoice AI
opinion: false
```

`opinion: true` shows an Opinion label. The journal, tag pages, and the JSON and RSS feeds pick the folder up with no other registration. Thai and English are the translated bodies. Every other interface language shows the English file and a notice that a translation is not available yet.

## Add exam questions

Questions live in `src/content/questions/en.ts` and `src/content/questions/th.ts`. Add the same `id` to both files, with the same `answer` index (`0`–`3`) and four choices in the same order. The exam shuffles display order by index, so the indexes must stay aligned even when the wording changes. Each attempt draws 20 questions from the bank, which must stay larger than 20. Languages without a bank fall back to English and say so on the exam.

## Add a language

1. Add the language to `LANGUAGES` in `src/lib/languages.ts`.
2. Add `src/lib/messages/<code>.ts` with every `MessageKey` from `src/lib/messages/en.ts`.
3. Register the catalog in `src/lib/i18n.tsx`.

Thai is chosen for Thai browsers. Any other browser language in the list is used when there is no saved choice. A saved choice lives in `localStorage` under `scai-lang`. Arabic sets `dir="rtl"`.

Posts, lessons, and questions do not have to exist in the new language. Missing content falls back to English with a notice.

## Exam gate

The question page is only rendered after **Start attempt** on `/exam` writes an attempt token to `sessionStorage`. Opening `/exam/session` directly does not include the questions.

When `VITE_TURNSTILE_SITE_KEY` is set, the landing page renders a Cloudflare Turnstile widget and blocks start until the widget returns a token. The site key does not exist yet, so the widget stays hidden. If a token is present, the browser asks `POST /api/turnstile/verify` on the worker. When `TURNSTILE_SECRET_KEY` is unset, that endpoint returns `{ ok: true, skipped: true }` and the exam starts. If the API cannot be reached, the exam still starts. A rejected token does not.

The question page blocks the context menu, copy, cut, paste, text selection, and a set of print, save, and devtools shortcuts. Print CSS hides the questions. Leaving the window or hiding the tab blurs the page and increments a counter. A name, attempt id, and clock are painted across the page as a watermark.

**A browser cannot fully prevent screen capture.** Operating-system screenshot tools, another device's camera, and extensions that the page cannot see will still copy the questions. These controls are deterrents, not a lock. The question bank is also shipped to the client until a server holds the session.

Pass mark is 80% (16 of 20). The timer is 30 minutes. After submit, the review shows the explanation for every question.

## Certificate

A passing attempt can download a PNG and a PDF. The image includes the name, score, date, certificate id, and a QR code. The page also `POST`s the certificate to the worker registry (`id`, `name`, `score`, `lang`, `issued_at`, `attempt_id`). The default API base is `https://pstack-academy-api.auichai-s2.workers.dev`. Override it with `VITE_API_BASE`.

`/verify/<id>` asks `GET /api/certificates/:id`. A registry hit shows **Verified**. A JSON `not_found` from this API shows **Not found**. If the API cannot be reached, the page falls back to the record embedded in `?d=` and keeps the warning that a crafted link is not proof.

## Worker

`worker/` is a separate Cloudflare Worker. It is not part of the Lovable or Vite build. Tests:

```sh
cd worker
bun test
```

### Deploy (Cloudflare free plan)

Do this from `worker/` after `bunx wrangler login`. Nothing in this repo deploys itself.

```sh
bunx wrangler d1 migrations apply pstack-academy --remote
bunx wrangler secret put TURNSTILE_SECRET_KEY
bunx wrangler deploy
```

`wrangler.toml` already names the worker `pstack-academy-api`, sets the account id, and binds D1 database `pstack-academy` as `DB`. Leave `TURNSTILE_SECRET_KEY` unset until the Turnstile secret exists: Siteverify is skipped and certificate registration still works. The secret is not stored in the repo. CORS allows `https://superchoice-academy-portal.lovable.app` plus `localhost` and `127.0.0.1`.
